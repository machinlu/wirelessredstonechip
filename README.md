### 📡 Hướng Dẫn Sử Dụng WirelessRedstone



#### 🔨 1. Công Thức Chế Tạo (Crafting)
* **Transmitter Chip (Đỏ):** `2 Redstone Dust` + `2 Observer`
* **Receiver Chip (Xanh):** `2 Observer` + `2 Redstone Dust`

#### 🎯 2. Đổi Tần Số (Signal ID)
* Đặt Chip vào **Đe (Anvil)** và đổi tên thành ID bạn muốn (Ví dụ: `door`).

#### 🧩 3. Gắn Chip Vào Khối (Attach to Block)
* Ghép **Transmitter Chip** với Nút/Cần gạt (Nguồn phát).
* Ghép **Receiver Chip** với Cửa/Đèn/Máy móc (Nơi nhận).

#### ⚡ 4. Điều Khiển
* Tác động vào khối phát $\rightarrow$ Tín hiệu truyền không dây tới khối nhận cùng Signal ID!

### 🕹️ How to Use



1. **Craft:**
   * **Transmitter Chip:** `2 Redstone Dust` + `2 Observers`
   * **Receiver Chip:** `2 Observers` + `2 Redstone Dust`
2. **Set Signal ID:** Rename the chip in an **Anvil** to set your custom frequency (e.g., `door`).
3. **Attach to Block:** Craft the chip together with your interactable block (Buttons, Levers, Doors, etc.).
4. **Control:** Activate your input block to wirelessly trigger the output block sharing the same Signal ID!
